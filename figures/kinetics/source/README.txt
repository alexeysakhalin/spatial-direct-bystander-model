Run python3 plot.py --output rebuilt_figure from this directory using the recorded Python and Matplotlib environment. The output directory must be new. Each panel and each curve or envelope layer has the same canvas and axis bounds at 600 dpi. White-background curve layers are supplied separately for assembly; their positions match the complete panels. The legend is separate. The assembled figure is provided as PNG and PDF. data.json contains every plotted value and is independent of the original host paths.
